# 花息 · PetalBreath

> 一款去医疗化、强治愈感、零焦虑的**产后盆底肌恢复（凯格尔运动）陪伴 Web App**。
>
> 以「植物生长」隐喻产后身体复苏，以「花朵开合」直觉化引导盆底肌的轻提与彻底放松。移动端优先（Mobile-first），桌面端默认以 9:16 手机视口居中呈现。

---

## ✨ 设计理念

产后恢复是一场温柔而持久的自我照料，而不该成为又一项带来愧疚感的打卡 KPI。**花息（PetalBreath）** 遵循三个核心原则：

1. **去医疗化（De-medicalized）**：用绘本彩铅与低饱和水彩纸质感替代冷冰冰的临床图表；生成的分享日签完全不出现“凯格尔/盆底肌”等字眼，只有属于自己的温柔暗号。
2. **只生长，不枯萎（Zero-Guilt）**：按累计滋养次数自然推进植物生长，不设断签惩罚、不显示冰冷的完成百分比，也没有刺眼的红叉。
3. **直觉化呼吸与多感官引导（Intuitive Multi-sensory）**：结合有机花朵开合动画、实时合成的自然音效（颂钵、水滴、白噪音雨声）与手机触觉振动，支持闭眼或静音跟练。

## 🌸 核心功能

### 1. 首页：花园与生长入口
- **时段温柔问候**：根据清晨、上午、午后、傍晚、夜晚自动切换问候语，营造片刻留白。
- **手绘盆栽成长反馈**：
  - 新用户初始（0 次）：暖土里刚探头的两片嫩芽（“一切恢复，都从这颗小芽开始”）。
  - 随累计训练次数逐步经历 **初芽期 → 抽枝期 → 含苞期 → 盛放期**，全程只生长、不枯萎。
- **弹性生长节奏设置**：右上角「节奏」抽屉可随时无负担切换：
  - **轻盈模式**：每天 1 次
  - **平衡模式**：每天 2 次
  - **标准模式**：每天 3 次
- **三重温柔入口**：
  - **开始本次唤醒**：首次体验自动进入「1 分钟体验 · 唤醒小芽」破冰课，日常自动匹配当前花期课程。
  - **纯放松 · 腹式呼吸（2 分钟）**：专为盆底肌高张力或睡前助眠设计，仅做舒缓吸呼，无收缩负担。
  - **今天太累了（休息日豁免）**：点击后画面落下温柔小雨、土壤变湿润并盖上一枚「休息小云朵」印章，记录为蓄力休息日。

### 2. 跟练页：花朵呼吸场
- **极简沉浸空间**：隐藏底部导航，大面积水彩纸留白，支持随时「暂歇一下」或「提前收尾」，方便带娃间隙随时中断。
- **练前 10 秒防代偿校准**：花朵完全舒展，轮播防代偿提示（放松肩膀、小腹、臀部和大腿，避免憋气）与当前阶段建议姿势。
- **有机花朵动态引导（`requestAnimationFrame` + `ease-in-out`）**：
  - **呼气 · 轻提（慢肌收紧）**：花瓣由外向内缓缓聚拢成饱满花苞，花心泛起暖光。
  - **稳住 · 保持**：花苞稳定并伴随微弱有机呼吸脉动。
  - **吸气 · 彻底松开（慢肌放松）**：花瓣完全舒展摊开，色彩转为轻盈。
  - **轻收 / 松开（快肌交替）**：1 秒轻快收拢、1 秒舒展放开。
- **自然音效 + 手机振动双引导**：
  - **Web Audio API 实时合成音效**：轻柔颂钵声（收紧）、清脆水滴声（放松）、轻木风铃（快肌交替）、暖音收尾和弦，以及可独立开关的轻柔雨声白噪音。
  - **Web Vibration API 手机触觉引导**：为收紧、保持、放松、快肌收放与完成设计了明显区分的温和振动节奏，方便闭眼跟练，开关偏好自动记忆。
- **练后滋养仪式**：不弹出机械的“完成 100%”，而是播放阳光与露珠落下、小花微微长高的治愈反馈动画，附带温柔夸奖，并可直接生成今日暗号日签。

### 3. 图鉴页：复苏手账与暗号日签
- **干花标本墙**：每完整养开一株花，即压制成手绘干花标本贴入图鉴，记录陪伴周数与花语；未盛放阶段以淡雅铅笔线稿柔和预告。
- **零愧疚手账日历**：用有机水彩圆点记录滋养日（单次为鼠尾草绿，多次呵护为干枯玫瑰粉），用小云朵贴纸记录休息日，未练习日期保持干净留白，绝无红叉。
- **暗号式水彩日签导出**：点击任意已解锁干花标本或日历记录，可切换诗意暗号文案（如“今天也温柔地托住了自己 · 3 min”），并通过 HTML5 Canvas 一键导出 **900×1200 高清 PNG** 水彩日签图片。

## 🌿 12 周课程体系（4 株花期）

课程以临床产后盆底肌渐进恢复逻辑为基础，按**累计完成次数**自然解锁下一花期：

| 阶段 | 花卉 | 周期 | 建议姿势 | 阶段目标 | 训练节奏 | 盛放累计次数 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **一** | **小雏菊（Daisy）** | 第 1–2 周 | 仰卧屈膝 | 唤醒与防代偿期 | 首次 1 分钟破冰（收2s/放4s × 6组）<br>日常慢肌（收3s/保1s/放5s × 8组） | 14 次 |
| **二** | **洋甘菊（Chamomile）** | 第 3–6 周 | 舒适坐姿 | 肌力建立期 | 慢肌（收4s/保1s/放6s × 10组）<br>+ 快肌（收1s/放1s × 10次） | 28 次（累计 42 次） |
| **三** | **郁金香（Tulip）** | 第 7–10 周 | 放松站姿 | 抗重力强化期 | 慢肌（收5s/保2s/放8s × 10组）<br>+ 快肌（收1s/放1s × 12次） | 28 次（累计 70 次） |
| **四** | **铃兰（Lily of the Valley）** | 第 11–12 周 | 站立动态 | 生活化巩固期 | 慢肌（收6s/保2s/放10s × 10组）<br>+ 快肌（15次）+ 生活预收缩提示 | 14 次（累计 84 次） |

## ☁️ 零愧疚反馈机制（LocalStorage 本地持久化）

所有训练记录与偏好均安全保存在浏览器本地 `localStorage` 中，无需注册登录，保护个人隐私：

- **昨日部分完成**（例如设定 3 次但只完成 1 次）：首页仅肯定做到的部分（“昨天给小芽晒了 1 次太阳，它已经稳稳扎根啦”），绝不提醒“漏了 2 次”。
- **昨日未练（0 次）**：植物保持鲜活不枯萎，画面飘起温柔清晨薄雾（“昨天带娃辛苦啦，小芽也陪你好好睡了一觉”）。
- **连续 3 天未达标**：温和弹出关怀卡片，询问是否愿意把节奏下调为「轻盈模式 · 每天 1 次」。
- **花期盛放 10 秒体感复盘**：每养开一株花，轻柔询问大笑、咳嗽或抱娃起身时是否感觉更稳；若走完完整 12 周仍无明显改善，会给予温和、不制造焦虑的医院盆底康复科评估建议。
- **体验演示入口**：在右上角「节奏」抽屉最底部的**「体验不同日常状态（演示预览）」**中，可一键预览初始小芽、昨日部分完成、清晨薄雾、连续忙碌降频提示、小雏菊盛放复盘以及 12 周全图鉴等全部状态。

## 🛠️ 技术栈

- **框架**：React 19 + TypeScript + Vite 8
- **样式**：Tailwind CSS v4
- **图标**：Lucide React
- **图形与导出**：自定义手绘风 SVG 植物与花朵动画 + HTML5 Canvas 高清日签渲染
- **音频与触觉**：原生 Web Audio API（零外部音频依赖）+ Web Vibration API
- **存储**：Browser LocalStorage

## 🚀 本地运行与构建

### 环境要求
- Node.js >= 18

### 启动开发服务器
```bash
# 1. 克隆仓库
git clone <你的仓库地址>
cd <仓库目录>

# 2. 安装依赖
npm install

# 3. 启动本地开发（默认端口 3000）
npm run dev
```
打开浏览器访问 `http://localhost:3000` 即可体验。

### 生产构建与类型检查
```bash
# TypeScript 类型检查
npm run lint

# 构建静态产物至 dist/
npm run build

# 本地预览生产构建
npm run preview
```

## 🌐 部署到 GitHub Pages

本项目已在 `vite.config.ts` 中配置 `base: './'`，可直接适配任意 GitHub 仓库子路径部署：

1. 在仓库中创建 `.github/workflows/deploy.yml`：
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm install
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
2. 前往 GitHub 仓库的 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 推送到 `main` 分支后等待 Actions 构建完成，即可使用 GitHub Pages 链接在手机浏览器中直接打开测试。

> **关于手机振动的浏览器说明**：Web Vibration API 目前主要在 Android 端 Chrome / Edge 等浏览器中原生支持；iOS Safari 及桌面端浏览器会自动优雅降级为静默模式，不影响视觉与音频跟练体验。

## 🤍 健康提示

本应用仅作为产后日常呼吸放松与盆底肌自我觉察的温和陪伴工具，不构成专业医疗诊断或治疗方案。建议产后 42 天复查确认恢复良好后再循序渐进开始练习；若练习过程中出现疼痛、明显坠胀或持续不适，请及时暂停并咨询妇产科或专业盆底康复医师。
